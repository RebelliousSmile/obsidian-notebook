# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Notebook is a fork of [Handbook](https://github.com/RebelliousSmile/obsidian-handbook), itself a fork of [Brumes](https://github.com/4rtamis/obsidian-brumes). Handbook's full history up to 2.8.6, the revision this fork started from, is preserved in its own repository and is not repeated here.

## [0.1.0]

### Changed

- Forked from Handbook 2.8.6: removed all tabletop-roleplaying content (City of Mist, Legend in the Mist, :Otherscape, the Adrenaline System and the Lantern integration) and renamed every internal identifier, path, CSS prefix and asset convention from Brumes/Handbook/game to Notebook/pack.
- Added the two native style packs, `gestion-projet` and `client-guide`, active from the first launch with no install step.
